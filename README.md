Python To-Do List

A simple, console-based To-Do List application built using Python. It helps users manage daily tasks by adding, viewing, completing, and deleting tasks. Task data is stored persistently using JSON.

Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Track task status (Pending / Done)
- Save tasks using JSON for data persistence

Technologies Used

- Python
- JSON

Project Structure

To-Do-List/
│
├── todolist.py
└── tasks.json

Note: "tasks.json" is automatically created when tasks are saved.

How to Run

1. Clone this repository:
   
   git clone https://github.com/shreeya-pareek/python-todo-list.git

2. Navigate to the project directory:
   
   cd python-todo-list

3. Run the Python file:
   
   python todolist.py
